# Kairos aperture mark

The new mark is an original abstract construction made for this project:

- an open arc represents attention and an unfinished learning journey;
- a grounded stem represents retained knowledge;
- a six-ray aperture represents insight arriving at the right moment.

It deliberately avoids reproducing the supplied literal head silhouette. The same geometry is used in the Compose mark, splash asset, adaptive launcher foreground, monochrome icon, and legacy launcher icon.
